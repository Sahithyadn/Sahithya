Restaurant Reservation System - Project Description
The Restaurant Reservation System is a web application that allows customers to book tables by submitting their name, phone number, and guest count via a form. The system updates the available seats dynamically based on the reservation.

Key Features:

Reservation Form: Customers enter their name, phone number, and guest count.
Seats Management: The available "Seats Left" decreases as reservations are made and increases when customers check out.
Reservation Table: Displays reservations with customer details, check-in time, check-out time, and a delete option.
Check-out & Deletion: Clicking "Click to Checkout" logs the checkout time and updates seats. Reservations can also be deleted.
Duplicate Name Handling: Alerts for duplicate names or overbooking.
